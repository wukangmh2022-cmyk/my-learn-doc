7.3 存算一体（Computing-in-Memory）的未来

概述

存算一体（Computing-in-Memory, CIM）是一种从根本上颠覆传统冯诺依曼架构的计算范式。它的核心思想是：让计算直接在数据存储的位置就地完成，而不是将数据搬运到处理器再计算。

这听起来理所当然，但它对 GPU 领域"通信是瓶颈"的根本假设发起了挑战。如果存算一体技术成熟，那句经典的"Hide communication behind computation"将物理反转，变成"Hide computation behind communication"——因为瓶颈从通信反转成了计算本身。

存算一体（Flash / ReRAM）让"计算藏在通信后"这个反直觉的表达，第一次有了物理基础。

工作原理：NOR Flash 模拟计算

物理基础

存算一体的最经典实现是基于 NOR Flash 的模拟计算阵列。它的工作原理非常简单——利用欧姆定律（V = IR）和基尔霍夫电流定律：

权重以电导值（G）的形式存储在 Flash 单元中
输入以电压值（V）的形式施加在位线上
输出电流（I = G × V）在列线上自然累加

I_out_j = Σ_i (G_ij × V_in_i)

这个公式，就是 向量-矩阵乘法（VMM）——正是神经网络中最核心的操作。

与传统 GPU 的对比

特性 传统 GPU / 冯诺依曼架构 NOR Flash 存算一体
核心瓶颈 通信（数据搬运）是瓶颈 计算（模拟运算慢）是瓶颈
谁"藏"谁 通信藏在计算后 计算藏在通信后
主要优势 极高算力，通用性强 极低功耗，几乎无数据搬运能耗
精度 高（FP32/FP64/BF16） 有限（通常 INT8，受限于模拟噪声）
应用场景 云端训练/推理 端侧极低功耗场景
技术成熟度 高度成熟 已量产，但生态仍在发展中

现状：能做什么？不能做什么？

已能做的：矩阵乘（MatMul）

存算一体的主战场是矩阵乘法——这正是它天生的能力。目前产业界的核心应用集中在 AI 推理的矩阵乘上：

  • 能效极高：基于 NOR Flash 的芯片能效可达 319.3 TOPS/W
  • 已有量产：知存科技 WTM2101（全球首颗大规模量产存算一体 SoC）
  • 端侧部署：已在百万级终端（耳机、智能摄像头）中实装

研究进展中的：非线性算子

对于 MatMul 以外的操作，学术界和工业界使用三种思路：

思路一：在模拟域里"硬计算"

用专用的 CMOS 模拟电路直接完成非线性计算，避免频繁的数模转换：

  • ReLU：已能支持，通过查找表或可重构电路实现
  • 激活函数（SiLU、GELU）：利用泰勒展开或分段拟合，在纯模拟域高效计算
  • 通用逻辑：利用 NOR Flash 多阈值电压特性，可配置出 AND、OR、XOR 等 16 种完备布尔逻辑

思路二：软硬件协同的"编译器魔法"

只让存算硬件做最擅长的事（大矩阵乘），其他活交给旁边数字核心：

Compiler 分析计算图：
┌─ MatMul/Conv     → 映射到存算阵列（模拟计算，高能效）
├─ ReLU/Add        → 可融合进存算阵列或由数字核心处理
├─ Softmax/LayerNorm → 交给 RISC-V/DSP 核心（数字计算）
└─ 控制流/复杂逻辑  → 交给通用处理器

思路三：架构层面的异构集成

三维堆叠异构：不同芯片层用不同工艺制造——SRAM 阵列做高速缓存，RRAM 阵列做非易失存储和矩阵计算。

当前还做不到的

限制 原因
高精度训练（FP32/FP64） 模拟电路受工艺波动和噪声影响，精度有限
复杂控制流 分支、循环、动态调度需要通用 ALU
软件生态兼容 无 CUDA 级别的工具链，需要专用编译器
ADC 瓶颈 模数转换器能耗可达芯片总能耗的 87%，面积达 75%

为什么存算一体如此重要

它打破了"内存墙"

在传统架构中，数据在内存和处理器之间来回移动所消耗的能量，占总能耗的 可达 90%。这就是所谓的"内存墙"或"冯诺依曼瓶颈"。

存算一体的核心贡献在于：从物理层面消灭了数据搬运这个环节。计算直接在存储数据的 Flash 阵列中完成，省下了搬运开销。

这也是为什么存算一体芯片能以极低功耗完成 AI 推理的核心原因。

它反转了"通信 vs 计算"的范式

你之前创造过一个精辟的表述——"Hide computation behind communication"。在传统 GPU 中，这句话是反直觉的，因为通信从来都是瓶颈。

但在存算一体中：

传统 GPU：           通信（数据搬运）→ 瓶颈，需要隐藏它
存算一体：           通信 ≈ 0（数据就地使用）→ 计算变成瓶颈
新范式：             计算藏在通信后 = 计算变得最慢，通信不再需要被"藏"

它正在发生

存算一体不是停留在学术论文中的概念，它已经在多个层面进入产业化：

公司/机构 进展
知存科技 全球首颗大规模量产存算一体 SoC（WTM2101），已部署百万级终端
后摩智能 M50 芯片可支持百亿级参数大模型端侧运行
清华大学 国际首款支持 FP16/FP32 高精度计算的存算一体芯片
中国移动 "芯易"软件引擎，兼容多种存算芯片并适配 PyTorch
炬芯科技 规划下一代技术实现 Transformer 全面支持

未来展望：一个异构的世界

存算一体不太可能完全取代 GPU，更可能扮演一个"最强辅助"的角色：

未来推理系统架构：

┌─────────────────────────────────────┐
│          CPU（逻辑控制大脑）          │
│     LayerNorm, Softmax, 控制流       │
└────────────┬─────────────────────────┘
             │
┌────────────▼─────────────────────────┐
│     存算一体阵列（算力心脏）          │
│     MatMul, Conv, Attention 核心      │
│     模拟计算，能效极高               │
└─────────────────────────────────────┘

它的角色是：

  1. 替代 Tensor Core 的位置——但不是替代整个 GPU
  2. 专注于大规模矩阵乘——天生擅长的操作
  3. 和通用核心协同——复杂操作交给 CPU/DSP
  4. 从端侧走向云端——现阶段在耳机/摄像头，未来可能在数据中心

正如一位业内专家所指出的：存算一体要对抗的并不是某款芯片，而是整个 NVIDIA CUDA 生态。这是一个软件生态的战争，而不仅仅是硬件的竞赛。

关键结论

  1. 物理原理优美：利用欧姆定律直接在 Flash 阵列中完成向量-矩阵乘法，通信开销为零
  2. 主战场是矩阵乘：当前产业界核心应用在 AI 推理的 MatMul，效率远超传统架构
  3. 非线性计算正在突破：ReLU 已支持，更复杂的算子通过三种思路（模拟域硬算、编译器调度、异构集成）逐步解决
  4. 精度和生态是硬伤：模拟精度有限（INT8 为主），且缺乏成熟的工具链和编程模型
  5. 前景广阔但角色明确：存算一体不会完全取代 GPU，但会在特定场景（端侧、低功耗）成为不可替代的选项

你最初的直觉完全正确：存算一体是用"通信=0"的物理特性，彻底反转了传统 GPU 的"通信是瓶颈"模型。它让"计算藏在通信后"第一次变得物理正确。

延伸：从架构视角看存算一体

将存算一体放在计算架构的光谱中看：

纯冯诺依曼 ←───────────── 纯存算一体
  │                           │
  GPU/CUDA                    NOR Flash CIM
  ├─ 通信是瓶颈                ├─ 计算是瓶颈
  ├─ 数据搬运占总能耗 90%      ├─ 数据搬运 ≈ 0
  ├─ 精度高/生态成熟           ├─ 精度有限/生态起步
  └─ 通用性强                  └─ 专精矩阵乘

未来的趋势不是二选一，而是融合——在通用 GPU 中集成更多的存内计算单元，让同一块芯片能根据不同任务类型，在"通信敏感"和"计算敏感"模式之间动态切换。
